<h1 align="center">吉大课表</h1>
<p align="center">把一周的课程，清楚地放在手机里。</p>
<p align="center">Android 8.0+ · v0.8.0 · 本地离线课表 · 清爽柔色主题 · 桌面小组件</p>

面向吉林大学本科生的非官方 Android 课程表应用。提供「学在吉大」课表自动导入、本地离线查看、整学期与单日课程管理，以及在手机桌面显示当天课程的桌面小组件。

> 当前为测试版本。自动导入已根据学校公开前端接口完成适配，尚未使用真实学生账户完成校园网实机端到端验收。登录兼容性、实际返回的课程范围和调课同步情况仍需核对。

## 下载与安装

**[下载 v0.8.0 安卓安装包](./jlu-timetable-0.8.0-debug.apk?raw=true)**（也可在仓库的 Releases 页下载）

- 系统要求：Android 8.0（API 26）及以上。
- 当前面向吉林大学本科生，导入或更新课表需要连接可访问学校服务的校园网。
- 安装包文件名：`jlu-timetable-0.8.0-debug.apk`，约 12.1 MiB。
- 当前安装包使用调试签名，是供测试使用的 APK。

下载后在安卓手机上打开 APK，按系统提示允许相应来源安装应用，再完成安装。如果链接打开的是文件页面，可使用页面的下载按钮保存 APK。

同签名旧版可直接覆盖安装，保留本地课表。卸载应用或清除应用数据会删除本地保存的内容。

## 功能

| 功能 | 说明 |
| --- | --- |
| 学校课表导入 | 在学校原登录页面完成认证，应用自动读取当前学期、各教学周的课程与节次时间，无需手动填写课表或校历 |
| 离线查看 | 完整校验通过后保存至本机，断网时显示已保存的课表 |
| 简洁周视图 | 固定显示周一至周日，首页保留课表、周次日期和设置入口 |
| 滑动切周 | 左右滑动查看不同教学周，单击左上角周数区域返回本周 |
| 单日课程管理 | 点击空白时间段，在浮窗中增加当天课程；点击已有课程可查看详情、修改或删除当天安排 |
| 整学期课程管理 | 按选定星期与节次增加每周重复的课程，或删除、恢复一门课程的整学期安排 |
| 独立课程配色 | 每门课程可单独选择颜色，整学期保持一致，重新导入后保留 |
| 地点简写 | 课程卡片、详情与桌面小组件统一显示「一教三阶」「三教103」等短名称，去掉重复校区与楼名 |
| 更新与冲突处理 | 保留个人安排；学校原安排发生变化或无法匹配时，可在设置中确认如何处理 |
| 桌面小组件 | 在桌面查看当天课程、时间、地点与教学周，满宽双列显示，支持离线、调整大小与暗色模式 |
| 暗色模式 | 应用与桌面小组件同步切换深色风格，偏好保存在本机 |

## 首次导入

1. 连接校园网，打开应用。
2. 点击首页右上角的设置图标。
3. 点击「登录学在吉大，一键导入」。
4. 在学校原登录页面完成认证，按页面要求处理验证码。需要查看微信验证码时，可以切换微信后返回。
5. 登录成功后，应用会尝试自动读取当前学期，并逐周获取课程和上课时间。
6. 全部数据校验通过后，保存到本地并返回课表。

首次启动显示空课表。导入失败时保留原有课表，可重新连接学校服务后重试。

## 日常使用

### 查看课程

- 左右滑动课表，切换教学周。
- 单击左上角「第 N 周」区域，回到当前教学周。
- 如果今天不在所选学期内，应用会提示切换学期。
- 点击课程色块，查看当天的时间、地点、教师和备注。

### 调整当天安排

**增加当天课程：** 点击空白时间段，在浮窗中填写课程名称、地点等信息。日期和节次会自动带入，也可以调整开始、结束节次。

**修改或删除当天课程：** 点击已有课程，在详情中选择「修改当天」或「删除当天课程」。删除前需要确认。

当天操作只影响所选的那一次安排，不会改变其他日期的同门课程。时间重叠时，应用会提示确认。

### 管理整学期课程

进入「设置 → 管理整学期课程」：

- **增加整学期课程：** 选择星期，可多选，再填写节次等信息；课程会在本学期每个教学周重复。
- **删除整学期课程：** 删除同名同教师课程在当前学期的全部时段，包括其附属的单日修改。
- **恢复整学期课程：** 在「已整学期删除」区域恢复，原有附属单日修改会保留。
- **编辑颜色：** 为每门课程单独选色，应用于整个学期及其附属单日修改。同名不同教师的课程分别设置。

整学期新增、删除记录和课程颜色在重新导入后保留。首页独立新增的单日课程作为独立事项管理。

### 更新学校课表

连接校园网后，再次从设置中执行一键导入。

更新只会在完整校验通过后替换学校来源课表；读取不完整或校验失败时，保留原数据。可在「设置 → 个人修改与恢复」查看当天修改、恢复原安排或处理冲突。

### 桌面小组件

「今日课程」小组件在桌面显示当天的日期、教学周、课程名称、上课时间和地点，读取本地数据库，无需打开应用或联网。

- **添加：** 在应用「设置 → 桌面小组件 → 添加到桌面」请求桌面添加；或长按桌面空白处 → 卡片／插件 → 搜索「吉大课表」→ 选择「今日课程」拖入桌面。
- **比例：** 提供「今日课程 5×2」（满宽短卡）、「今日课程 5×4」（满宽高卡）、「今日课程 2×2」（小卡）三个预设；在 4 列网格机型上由桌面钳制为满宽。
- **显示：** 宽屏自动双列排布当天课程，窄屏回退单列。课程卡片使用 WakeUp 参考图中的浅色底与细色条，宽高比约为 3.1∶1，改变外框高度时保持课程卡片比例。
- **操作：** 点击日期、课程或空白提示打开应用并回到当天所在周；点击右上角课程数量重新读取本地数据；拖动边缘改变宽高。
- **刷新：** 应用导入、课程增删、颜色修改、学期或主题切换后会请求刷新；同时设置系统周期更新、跨日更新、设备重启和时间变化后的更新。系统休眠或厂商后台限制可能推迟后台刷新，可点击课程数量手动刷新。刷新不会自动联网重新导入学校数据。

## 本地存储与隐私

- 课表、学期信息、个人修改、整学期删除记录和课程颜色保存在手机本地数据库。
- 账号、密码和验证码在学校原登录页面完成输入与认证；应用代码不会主动采集或保存这些字段。
- 学校网页使用的必要登录会话可能由应用内 WebView 保留。
- 当前没有课表云同步功能，应用禁止系统云备份。
- 卸载应用或清除应用数据会删除本地课表。

## 当前版本与验证情况

当前版本：**v0.8.0**。

本版更新：蓝色图标与设置页、灰色长条按钮、十六种课程配色；主课表课程色略加深且不显示左侧色条，桌面小组件保留参考卡片比例。上课地点统一简写，并为地点预留显示空间。

- 116 项自动测试通过，覆盖课程解析、日期和周次、单日与整学期操作、数据库迁移、课程配色及手选颜色避让、地点简写、界面交互，以及桌面小组件双列行渲染与 inflate 合规性。
- 已验证整学期个人新增、删除记录和颜色在重新导入、数据库关闭重开后保留。
- 桌面小组件已在 OPPO Find X8s+（ColorOS 16 / Android 16）实机验证：应用内「添加到桌面」可正常唤起系统确认窗口，满宽双列与自动填满高度按预期工作。
- 课表以学校平台实际返回的数据为准；平台未返回的调课、补课或未排时间课程不会被推测补入。

本地自动测试不能代替真实手机与学校账户验收。当前尚未完成校园网真实登录、实际课表逐项核对及不同手机键盘行为的实机验证。
